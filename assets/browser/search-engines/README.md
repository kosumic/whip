# Search-engine icons

Standalone SVG provider icons bundled for identification in the browser
search-engine selector. Rendered as vectors through `react-native-svg` on Android
and iOS, without network requests or embedded bitmap images.
Downloaded unchanged on 2026-09-30.

- Google: [Google-hosted G icon](https://www.gstatic.com/images/branding/productlogos/googleg/v6/24px.svg).
- DuckDuckGo: `DuckDuckGo Logo- Dax Solo.svg` from the
  [official brand package](https://staticcdn.duckduckgo.com/press/DuckDuckGo-Brand-Logo.zip)
  linked by the [press page](https://duckduckgo.com/press).
- Bing: Microsoft Fluent icon from
  [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Bing_Fluent_Logo.svg),
  attributed there to Microsoft, with source `bing.com` and marked PD-textlogo.
  [SVG source](https://upload.wikimedia.org/wikipedia/commons/9/9c/Bing_Fluent_Logo.svg).
- Brave: [official Brave Search SVG favicon](https://cdn.search.brave.com/serp/v3/_app/immutable/assets/favicon.CVXAaejQ.svg).

Provider names and logos remain their respective owners' trademarks.
